# SpectralEO website

Astro version of the SpectralEO website with a Markdown-powered company blog, tag pages, and a separate Publications section for Spectral Reflectance and The Morning Backscatter.

## Local development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Astro will print the local URL, usually:

```bash
http://localhost:4321/
```

Build the static site:

```bash
npm run build
```

Preview the built site locally:

```bash
npm run preview
```

## Suggested branch workflow

From the existing repository:

```bash
git checkout main
git pull
git checkout -b astro-blog
```

Replace the old static site files with this Astro version, then run:

```bash
npm install
npm run dev
```

When ready:

```bash
git add .
git commit -m "Migrate website to Astro with blog"
git push -u origin astro-blog
```

The included GitHub Actions workflow deploys only from `main`, so pushing `astro-blog` should not replace the live site.

## Blog posts

Blog posts live in:

```text
src/content/blog/
```

Create a new Markdown file with front matter like this:

```md
---
title: "Post title"
description: "Short summary for cards, SEO, and social previews."
pubDate: 2026-06-06
tags:
  - "Prototype"
  - "Agentic AI"
  - "Earth Observation"
draft: false
---

Post body here.
```

Use tags to distinguish the format and topic of each post. Suggested format tags:

```text
Prototype
R&D
Technical Article
Company Update
Opinion
Case Study
Explainer
```

Suggested topic tags:

```text
Agentic AI
GeoAI
Downstream EO
STAC
Quality Control
Cal/Val
Reporting
Scientific Communication
```

Every tag automatically gets a page at:

```text
/blog/tags/<tag-slug>/
```

Set `draft: true` to keep a post out of the build.

## Deployment

The GitHub Actions workflow is in:

```text
.github/workflows/deploy.yml
```

It deploys only when changes are pushed to `main`, or when you manually run the workflow from GitHub Actions.

The custom domain is preserved through:

```text
public/CNAME
```

## Project notes

- The current SpectralEO visual identity is preserved in `src/styles/global.css`.
- Static assets are in `public/assets/`.
- The homepage is `src/pages/index.astro`.
- The blog index is `src/pages/blog/index.astro`.
- Individual blog pages are generated by `src/pages/blog/[...slug].astro`.
- Tag pages are generated by `src/pages/blog/tags/[tag].astro`.
